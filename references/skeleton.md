# 锻造骨架模板（阶段 3 用）

**选型**：交付形态是单轮/多轮对话 prompt → 对话型；是 agent system prompt / 长期角色 → agent 型。可混合，但骨架决定评估清单。

## 对话型骨架（八格）

1. **角色锚**：一句话、一个具体人设（领域 + 经验刻度 + 风格粒度），不开多重身份。参考句式「You are a senior X with N years of Y」/「你是一位…」
2. **上下文**：使用者情况 / 受众 / 当前水平，复用成分抽 `{{变量}}`
3. **任务动词**：动词开头 + 可交付物名词化；验收可测（「写得一版」不合格，「含 N 个要点的 markdown 表」合格）
4. **硬约束**：长度 / 格式 / 禁项，能用数字就用数字；风格约束（口吻 / 受众）单独列
5. **事实纪律**：不确定就说不确定，不编数据、不编引用
6. **输出格式**：给结构模板或一个示例片段（1 个样例 > 3 段描述）
7. **few-shot**（可选）：一组 输入→输出 样例
8. **质量门**：交稿前自检清单（覆盖全部交付物？禁项未犯？长度达标？）

## agent 型骨架（七段）

1. **Identity**：名字 + 使命一句话 + 服务对象
2. **Capabilities 边界**：能做 / 不做清单，含最大动作权限
3. **工具纪律**：每个工具——何时调用、调用前后各记录什么、失败怎么降级
4. **循环控制**：何时终止、何时问人 vs 自决、双重检查点
5. **输出契约**：默认形态 / 语气 / 语言；何时给摘要 vs 全量
6. **防幻觉条**：不臆造 API 与事实、引用来源、能力外直接说明
7. **失败路径**：常见错误场景 → 标准动作（例：外部服务挂 →告知用户哪句话 + 保留什么现场）

## 锻造判断规则

- 原稿逐句归格：有效任务保留；空话（「你是全世界最棒的…」「请你认真负责…」）砍掉，其意图转写成约束或质量门
- 两格冲突时：约束服从任务，格式服从使用场景
- 字数纪律：宁短勿松；八格不必全占——删掉对交付物没贡献的格子
- 变量化：明显反复使用的成分抽成 `{{占位符}}`，注释一行写明取值建议
- 产品 system prompt 对标拆出来的段落（工具纪律 / 循环控制 / 防幻觉）只借组织方式，措辞自己写
